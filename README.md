
# Le Colonel 🧀

Site de découverte et de classification des fromages.

## Fichiers

- index.html : accueil et catalogue.
- styles.css : design du site.
- data.js : données des fromages.
- app.js : recherche, filtres et fiches.
- quiz.html : page du quiz.
- quiz.js : questions et statistiques.

## Installation

1. Créer un dépôt GitHub nommé le-colonel.
2. Ajouter les six fichiers du site à la racine.
3. Ouvrir Settings.
4. Ouvrir Pages.
5. Choisir Deploy from a branch.
6. Sélectionner main et /(root).
7. Enregistrer.

Les statistiques du quiz sont sauvegardées dans le navigateur.

Les prix sont indicatifs et doivent être vérifiés.
